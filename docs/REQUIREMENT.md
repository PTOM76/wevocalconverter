# 要件定義
WeVocalConverter が何を目指し、どこまでできているか。

関連: [README](../README.md)

## 概要
ブラウザ上で音声ファイルの形式（WAV、MP3 など）を変換するツール。複数のファイルをまとめて変換し、1 つずつ、または ZIP でまとめて保存できる。画面を持たないライブラリとしても使用できる。

## 方針

| 方針 | 理由 |
| --- | --- |
| インストール不要で、ブラウザだけで動く | 気軽に使えることを優先するため |
| 音声ファイルをサーバーへ送らない | 素材の権利やプライバシーを気にせず使用できるようにするため |
| WeVocalSynth、WeVocalExtractor と同じ部品で作る | 読み込みと書き出しは wevocal-lib（Synth の書き出しと同じ）、画面は PevenMUI、キューと ZIP は Extractor のもの。操作感をそろえ、直すところを 1 か所にするため |
| ライブラリ（`src/`）と画面（`app/`）に分ける | Extractor と同じ。形式を増やす部品を、あとで Synth の追加機能からも使えるようにするため |

## 機能

### MVP

| 要件 | 内容 | 状態 |
| --- | --- | --- |
| 読み込み | 複数のファイル、ドラッグ＆ドロップ。ブラウザで読める形式（WAV、AIFF、MP3、M4A、FLAC、OGG、Opus、WebM など。AIFF は wevocal-lib が自前で読む） | 済み |
| 出力の形式 | WAV（16bit、24bit、32bit float）、MP3、Opus | 済み |
| 出力の設定 | ビットレート（MP3、Opus）、サンプルレート（元のまま、または選んだ値。Opus は 48kHz）、モノラルにする | 済み |
| 変換の一覧 | 並べたファイルを順に変換し、ファイルごとに進み具合を表示する。中止、やり直し、削除 | 済み |
| 試聴と保存 | 変換したファイルの試聴、1 つずつの保存（元の名前＋出力の拡張子）、ZIP でまとめて保存 | 済み |
| ライブラリ | `convert(file, options)` → Blob。React に依存しない。進み具合と中止は Extractor とそろえる | 済み |

### 対象外（MVP）
ブラウザが読めない形式の読み込み（WMA、APE など）、WAV、MP3、Opus 以外の出力、範囲の切り出しや音量などの編集、メタデータ（タグ、アートワーク）、WeVocalSynth の追加機能としての提供。

### MVP の後の候補
- 出力の形式を増やす（FLAC、AAC、ALAC など。ブラウザで作れるか調べる）
- ブラウザが読めない形式の読み込み
- メタデータの引き継ぎ
- ノーマライズ、両端のフェード（WeVocalSynth の書き出しと同じもの）

## WeVocalSynth との関係
今のところ、Synth から追加機能としては使わない。Synth の書き出しは同じ wevocal-lib の部品で、WAV、MP3、Opus は Synth だけで作れるため。

使うとしたら「対応する形式を増やす追加機能」にする。エンコーダーとデコーダー（wasm）は大きくなりがちなので、使う人だけが導入し、普段の Synth は軽いままにする。

- 出力を増やす: FLAC、AAC（M4A）、ALAC など。Synth の書き出しの形式の選択肢に足す
- 入力を増やす: ブラウザが読めない形式（WMA、APE、Safari 以外での ALAC など）。Synth で開くとき、ブラウザで読めなければ追加機能で読み直す

そのため、形式を増やすときは、エンコーダーとデコーダーをライブラリ（`src/`）に置く。

## 非機能要件

| 項目 | 目標 |
| --- | --- |
| 処理速度 | 数分の曲を、待ち時間が気にならない程度で変換する |
| 応答性 | 重い処理（MP3 のエンコードなど）は Worker で行い、画面を止めない |
| 対応環境 | PC とスマホのモダンブラウザ。オフラインでも使える（PWA）。Opus の出力は WebCodecs が使えるブラウザに限る |
